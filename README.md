# Familiearchief Tichem

Een statische, interactieve stamboom van de rechte Tichem-lijn. Open `index.html` lokaal of publiceer de repository met GitHub Pages vanaf `main` en `/ (root)`.

## Gegevens en bronnen

De persoonsprofielen staan in `script.js`. Elk profiel verwijst naar een bron in de `sources`-lijst. De oudste verbinding met Claes Tijgon/Tichon is een hypothese; de Hugenotenafkomst is niet bewezen. De verbinding van de levende generaties met Cornelis Tichem (1897–1979) komt uit door de familie verstrekte informatie en verdient nog een directe akte.

Genealogische websites zijn gebruikt als wegwijzers. Controleer namen, data en verwantschappen waar mogelijk in originele akten. Verschillende publicaties geven voor Cornelis Tichem rond 1800 een ander geboortejaar.

## Publiceren op GitHub Pages

In de repository: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. Omdat de site alleen HTML, CSS en JavaScript gebruikt, is geen buildstap nodig.

## Privacy

Voor levende personen worden geen geboortedata, adressen of andere privégegevens getoond. Controleer aanvullingen voordat je ze in een openbare repository zet.
